Le groupe verbal

Français CM2 — Comprendre le groupe verbal, le verbe, le COD, le COI, le COS et les compléments circonstanciels.

📘 1. Qu'est-ce que le groupe verbal ?

Définition : Le groupe verbal (GV) est un groupe de mots organisé autour d'un verbe. Il indique généralement ce que fait le sujet ou ce qui lui arrive.

Dans une phrase, le groupe verbal constitue avec le groupe sujet l'un des éléments essentiels de la phrase.

Exemple :

Le petit garçon mange une pomme.
→ Groupe sujet : Le petit garçon
→ Groupe verbal : mange une pomme
Autre exemple :

Les élèves révisent leurs leçons.
→ Groupe sujet : Les élèves
→ Groupe verbal : révisent leurs leçons

🔹 2. Le verbe, noyau du groupe verbal

Le verbe est le mot principal du groupe verbal. Il exprime une action, un état ou un événement.

Exemples :
  • Awa lit un livre.
  • Les enfants jouent dans la cour.
  • Mon frère semble fatigué.

Pour trouver le verbe, on peut modifier le temps de la phrase. Le mot qui change est généralement le verbe.

Aujourd'hui, Paul joue au football.
Hier, Paul jouait au football.
Demain, Paul jouera au football.

🎯 3. Le complément d'objet direct (COD)

Le COD complète directement le verbe. Il répond généralement aux questions « qui ? » ou « quoi ? » après le verbe.
Exemple :

Fatou mange une mangue.

Fatou mange quoi ? → une mangue
Donc « une mangue » est le COD.
Le maître explique la leçon.

Le maître explique quoi ? → la leçon.
→ « la leçon » est COD.

Comment reconnaître le COD ?

  1. Je trouve le verbe.
  2. Je pose la question « qui ? » ou « quoi ? ».
  3. La réponse est directement reliée au verbe.

🎯 4. Le complément d'objet indirect (COI)

Le COI complète le verbe indirectement. Il est généralement introduit par une préposition comme à, de, pour, etc.
Exemple :

Awa parle à sa mère.

Awa parle à qui ? → à sa mère.
→ « à sa mère » est COI.
Karim se souvient de son enfance.

Karim se souvient de quoi ? → de son enfance.
→ « de son enfance » est COI.

Comment reconnaître le COI ?

  1. Je trouve le verbe.
  2. Je pose « à qui ? », « à quoi ? », « de qui ? » ou « de quoi ? ».
  3. La réponse est reliée au verbe par une préposition.

🎯 5. Le complément d'objet second (COS)

Le COS est un complément d'objet qui accompagne déjà un autre complément d'objet, généralement un COD ou un COI.
Exemple :

Le professeur explique la leçon aux élèves.

« la leçon » → COD
« aux élèves » → COS
Maman offre un cadeau à son fils.

« un cadeau » → COD
« à son fils » → COS
À retenir : Le COS n'est pas simplement « un COI ». On parle de COS lorsqu'un autre complément d'objet est déjà présent dans la phrase.

🌍 6. Les compléments circonstanciels

Les compléments circonstanciels donnent des informations supplémentaires sur les circonstances de l'action.

Le complément circonstanciel de temps

Nous partirons demain matin.
→ Quand partirons-nous ?
→ demain matin = complément circonstanciel de temps.

Le complément circonstanciel de lieu

Les enfants jouent dans la cour.
→ Où jouent les enfants ?
→ dans la cour = complément circonstanciel de lieu.

Le complément circonstanciel de manière

Elle travaille avec soin.
→ Comment travaille-t-elle ?
→ avec soin = complément circonstanciel de manière.

Le complément circonstanciel de cause

Il reste à la maison à cause de la pluie.
→ Pourquoi reste-t-il à la maison ?
→ à cause de la pluie = complément circonstanciel de cause.

Le complément circonstanciel de but

Il travaille pour réussir.
→ Dans quel but travaille-t-il ?
→ pour réussir = complément circonstanciel de but.

📋 7. Tableau récapitulatif

COD → qui ? quoi ?

COI → à qui ? à quoi ? de qui ? de quoi ?

COS → deuxième complément d'objet

CCT → quand ?

CCL → où ?

CCM → comment ?

CCC → pourquoi ? pour quelle cause ?

CCB → dans quel but ?

🧠 8. Méthode pour analyser le groupe verbal

Étape 1 : Je cherche le verbe conjugué.

Étape 2 : Je cherche le groupe verbal.

Étape 3 : Je regarde si le verbe possède un COD.

Étape 4 : Je cherche éventuellement un COI ou un COS.

Étape 5 : Je cherche les compléments circonstanciels.

Étape 6 : Je vérifie le rôle de chaque groupe de mots.
Exemple complet :

Hier, Paul a offert un cadeau à sa sœur dans la cour.

Verbe → a offert
COD → un cadeau
COS → à sa sœur
CCT → Hier
CCL → dans la cour

✏️ 9. Exercices

Exercice 1 — Trouve le verbe

Souligne mentalement le verbe dans chaque phrase.

  1. Les enfants jouent dans la cour.
  2. Mariam prépare le repas.
  3. Nous regardons un film.
  4. Le professeur explique la leçon.
Correction :

1. jouent
2. prépare
3. regardons
4. explique

Exercice 2 — Trouve le COD

  1. Awa mange une orange.
  2. Le garçon lit un livre.
  3. Maman prépare le dîner.
  4. Les élèves écrivent une rédaction.
Correction :

1. une orange
2. un livre
3. le dîner
4. une rédaction

Exercice 3 — COD ou COI ?

  1. Il regarde la télévision.
  2. Elle parle à son frère.
  3. Nous aidons notre professeur.
  4. Il pense à ses vacances.
Correction :

1. la télévision → COD
2. à son frère → COI
3. notre professeur → COD
4. à ses vacances → COI

Exercice 4 — Trouve les compléments circonstanciels

  1. Nous partirons demain.
  2. Les élèves travaillent dans la classe.
  3. Il répond calmement.
  4. Elle étudie pour réussir.
Correction :

1. demain → CCT
2. dans la classe → CCL
3. calmement → CCM
4. pour réussir → CCB

Exercice 5 — Analyse complète

Le samedi matin, les élèves rangent soigneusement leurs livres dans la bibliothèque.

Correction :

Verbe → rangent
COD → leurs livres
CCT → Le samedi matin
CCM → soigneusement
CCL → dans la bibliothèque

📚 11. L'essentiel à retenir

  • Le groupe verbal est organisé autour d'un verbe.
  • Le COD complète directement le verbe.
  • Le COI complète indirectement le verbe.
  • Le COS est un deuxième complément d'objet dans une phrase qui possède déjà un autre complément d'objet.
  • Le CCT indique le temps.
  • Le CCL indique le lieu.
  • Le CCM indique la manière.
  • Les compléments circonstanciels apportent des informations sur les circonstances de l'action.
  • Pour analyser une phrase, il faut d'abord trouver le verbe puis identifier les différents compléments.
