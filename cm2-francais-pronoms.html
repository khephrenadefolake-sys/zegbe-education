Les pronoms

Français CM2 — Reconnaître, identifier et utiliser les différents types de pronoms.

📘 1. Qu'est-ce qu'un pronom ?

Définition : Un pronom est un mot qui peut remplacer un nom, un groupe nominal ou désigner une personne ou une chose sans répéter son nom.
Exemple :

Awa a acheté un livre. Elle lit le livre.

« Elle » remplace « Awa ».
Moussa aime cette voiture. Il veut l'acheter.

« Il » remplace « Moussa ».

👤 2. Les pronoms personnels

Les pronoms personnels servent notamment à désigner les personnes qui parlent, celles à qui l'on parle ou celles dont on parle.

Pronoms personnels sujets :
  • je
  • tu
  • il
  • elle
  • on
  • nous
  • vous
  • ils
  • elles
Exemples :
  • Je travaille.
  • Nous étudions.
  • Ils jouent.
  • Elle chante.

🔑 3. Les pronoms possessifs

Les pronoms possessifs indiquent à qui appartient une personne ou une chose.

Exemples :
  • le mien / la mienne
  • le tien / la tienne
  • le sien / la sienne
  • le nôtre / la nôtre
  • le vôtre / la vôtre
  • le leur / la leur
Exemple :

Ce livre est le mien.

Cette maison est la leur.

👉 4. Les pronoms démonstratifs

Les pronoms démonstratifs servent à désigner une personne, une chose ou un groupe déjà connu.

Principaux pronoms :
  • celui
  • celle
  • ceux
  • celles
  • ce
  • ceci
  • cela
  • ça
Exemple :

Je préfère celui de gauche.

Celles qui travaillent réussiront.

🔗 5. Les pronoms relatifs

Les pronoms relatifs servent à relier une proposition à un nom ou groupe nominal appelé antécédent.
Principaux pronoms relatifs :
  • qui
  • que
  • quoi
  • dont
  • où
  • lequel
  • laquelle
  • lesquels
  • lesquelles
Exemple :

Voici le livre que j'ai acheté.

« que » est un pronom relatif. Son antécédent est « le livre ».
L'élève qui travaille réussira.

« qui » reprend « l'élève ».

❓ 6. Les pronoms interrogatifs

Les pronoms interrogatifs servent à poser une question.

Exemples :
  • qui ?
  • que ?
  • quoi ?
  • lequel ?
  • laquelle ?
  • lesquels ?
  • lesquelles ?
Exemples :

Qui vient ?

Lequel préfères-tu ?

Que veux-tu ?

🌍 7. Les pronoms indéfinis

Les pronoms indéfinis désignent une personne, une chose ou une quantité de manière imprécise.

Exemples :
  • quelqu'un
  • personne
  • chacun
  • tout
  • rien
  • certains
  • plusieurs
  • aucun
Exemples :

Quelqu'un frappe à la porte.

Personne n'est venu.

Chacun doit travailler.

⚠️ 8. Pronom ou déterminant ?

Il faut faire attention : certains mots peuvent être des déterminants ou des pronoms selon leur emploi dans la phrase.
Déterminant :

Cette maison est grande.

« cette » accompagne le nom « maison ».
Pronom :

Je préfère celle-ci.

« celle » remplace un nom.
Astuce :

Si le mot accompagne un nom, il peut être déterminant.

Si le mot remplace un nom ou un groupe nominal, il peut être pronom.

🧠 9. Comment identifier un pronom ?

Étape 1 : Observe le mot.

Étape 2 : Vérifie s'il remplace un nom ou un groupe nominal.

Étape 3 : Cherche le type de pronom.

Étape 4 : Observe son rôle dans la phrase.
Exemple :

La fille regarde son frère. Elle lui parle.

« Elle » remplace « la fille ». → pronom personnel.

« lui » remplace « à son frère ». → pronom personnel.

✏️ 10. Exercices

Exercice 1 — Trouve les pronoms

  1. Elle joue dans la cour.
  2. Nous préparons notre travail.
  3. Celui-ci est mon préféré.
  4. Quelqu'un frappe à la porte.
Correction :

1. Elle → pronom personnel
2. Nous → pronom personnel
3. Celui-ci → pronom démonstratif
4. Quelqu'un → pronom indéfini

Exercice 2 — Indique le type de pronom

  1. Ils arrivent demain.
  2. Lequel choisis-tu ?
  3. Cette voiture est la mienne.
  4. Celui-là est plus grand.
  5. Personne ne répond.
Correction :

1. Ils → personnel
2. Lequel → interrogatif
3. La mienne → possessif
4. Celui-là → démonstratif
5. Personne → indéfini

Exercice 3 — Trouve l'antécédent

Le garçon qui parle est mon frère.

Correction :

Le pronom relatif « qui » a pour antécédent le garçon.

Exercice 4 — Pronom ou déterminant ?

  1. Cette maison est belle.
  2. Celle-ci est magnifique.
  3. Mon livre est neuf.
  4. Le mien est ancien.
Correction :

1. Cette → déterminant démonstratif
2. Celle-ci → pronom démonstratif
3. Mon → déterminant possessif
4. Le mien → pronom possessif

Exercice 5 — Remplace le groupe nominal

Remplace le groupe nominal souligné par un pronom.

  1. Awa arrive. → ______ arrive.
  2. Les enfants jouent. → ______ jouent.
  3. Paul et moi travaillons. → ______ travaillons.
  4. La voiture appartient à Mariam. → Elle est ______.
Correction :

1. Elle arrive.
2. Ils jouent.
3. Nous travaillons.
4. Elle est la sienne.

🧠 11. Quiz

1. Dans « Elle chante », quel est le type de « Elle » ?

2. Quel mot est un pronom relatif ?

3. Quel est le pronom possessif ?

4. Quel est le pronom démonstratif ?

5. Dans « Quelqu'un arrive », « Quelqu'un » est :

📚 12. L'essentiel à retenir

  • Le pronom peut remplacer un nom ou un groupe nominal.
  • Les pronoms personnels désignent les personnes ou les êtres dont on parle.
  • Les pronoms possessifs indiquent l'appartenance.
  • Les pronoms démonstratifs servent à désigner.
  • Les pronoms relatifs relient une proposition à son antécédent.
  • Les pronoms interrogatifs servent à poser des questions.
  • Les pronoms indéfinis désignent de manière imprécise.
  • Un pronom ne doit pas être confondu avec un déterminant.
