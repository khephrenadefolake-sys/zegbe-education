Chapitre 1 : La phrase

Français CM2 — Types de phrases, formes de phrases, phrase simple et phrase complexe.

📖 1. Qu'est-ce qu'une phrase ?

Définition : Une phrase est un ensemble de mots organisé qui a un sens. Elle commence généralement par une majuscule et se termine par un signe de ponctuation.

Exemples

Exemple 1 :
Les élèves travaillent en classe.
Exemple 2 :
Où vas-tu ?
Exemple 3 :
Ferme la porte !
À retenir : Une phrase doit être correctement construite et avoir un sens.

🎯 2. Les types de phrases

On distingue principalement quatre types de phrases.

Type Rôle Exemple
Déclarative Elle donne une information. Paul lit un livre.
Interrogative Elle pose une question. Paul lit-il un livre ?
Exclamative Elle exprime un sentiment ou une émotion. Quel beau livre !
Impérative / injonctive Elle donne un ordre, un conseil ou une interdiction. Lis ce livre !

🔄 3. Les formes de phrases

Une phrase peut également avoir différentes formes.

La forme affirmative

Exemple : Awa aime les mathématiques.

La forme négative

Exemple : Awa n'aime pas les mathématiques.

La forme active

Exemple : Le professeur explique la leçon.

La forme passive

Exemple : La leçon est expliquée par le professeur.
Attention : Le type et la forme d'une phrase sont deux notions différentes. Une phrase peut donc être, par exemple, déclarative et négative.

🧩 4. Phrase simple et phrase complexe

La phrase simple

Une phrase simple contient généralement un seul verbe conjugué.
Exemple :
Les enfants jouent.

Le verbe conjugué est : jouent.

La phrase complexe

Une phrase complexe contient plusieurs verbes conjugués.
Exemple :
Les enfants jouent parce qu'ils ont terminé leur travail.

Les verbes conjugués sont : jouent et ont terminé.

Astuce : Pour savoir si une phrase est simple ou complexe, cherche d'abord les verbes conjugués.

✒️ 5. Les signes de ponctuation

Signe Nom Exemple
. Point Il travaille.
? Point d'interrogation Travaille-t-il ?
! Point d'exclamation Quel travail !
; Point-virgule Il travaille ; il progresse.
: Deux-points Il dit : « Je travaille. »

✏️ 6. Exercices

Exercice 1 — Identifier le type

Indique si chaque phrase est déclarative, interrogative, exclamative ou impérative.

  1. Quelle magnifique journée !
  2. Est-ce que tu as terminé ton exercice ?
  3. Les élèves entrent dans la classe.
  4. Range ton cahier.
Correction :

1. Exclamative
2. Interrogative
3. Déclarative
4. Impérative / injonctive

Exercice 2 — Phrase simple ou complexe ?

Indique si chaque phrase est simple ou complexe.

  1. Le soleil brille.
  2. Les enfants jouent et leur mère prépare le repas.
  3. Nous avons terminé notre travail.
  4. Quand il pleut, les élèves restent en classe.
Correction :

1. Simple — un verbe conjugué : brille.
2. Complexe — deux verbes conjugués : jouent, prépare.
3. Simple — un verbe conjugué : avons terminé.
4. Complexe — deux verbes conjugués : pleut, restent.

Exercice 3 — Transformer à la forme négative

Transforme les phrases suivantes à la forme négative.

  1. Fatou aime le français.
  2. Les élèves jouent dans la cour.
  3. Il comprend la leçon.
Correction :

1. Fatou n'aime pas le français.
2. Les élèves ne jouent pas dans la cour.
3. Il ne comprend pas la leçon.
