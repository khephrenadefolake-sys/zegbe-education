Chapitre 2 : Le groupe nominal

Français CM2 — Déterminant, nom, adjectif qualificatif et expansions du nom.

📖 1. Qu'est-ce qu'un groupe nominal ?

Définition : Un groupe nominal, appelé aussi GN, est un groupe de mots organisé autour d'un nom.
Exemple :

Le petit garçon joue dans la cour.

Dans le groupe nominal « le petit garçon », le mot principal est garçon.

À retenir : Le nom est généralement le noyau du groupe nominal.

🔎 2. Les éléments du groupe nominal

Un groupe nominal peut être composé de plusieurs éléments.

Élément Rôle Exemple
Déterminant Il accompagne et précise le nom. Le garçon
Nom Il constitue le noyau du GN. Le garçon
Adjectif qualificatif Il donne une précision sur le nom. Le garçon gentil
Complément du nom Il apporte une précision sur le nom. Le livre de français

📝 3. Les déterminants

Le déterminant accompagne généralement le nom. Il permet notamment de connaître son genre et son nombre.

Les articles définis

le, la, l', les

Exemple : le garçon, la fille, les élèves.

Les articles indéfinis

un, une, des

Exemple : un livre, une maison, des enfants.

Les déterminants possessifs

mon, ton, son, ma, ta, sa, notre, votre, leur, leurs...

Exemple : mon cahier, notre classe, leurs livres.

Les déterminants démonstratifs

ce, cet, cette, ces

Exemple : ce garçon, cette fille, ces élèves.

Les déterminants interrogatifs et exclamatifs

quel, quelle, quels, quelles

Exemple : Quelle belle journée !

Attention : Le déterminant s'accorde avec le nom en genre et en nombre.

🔤 4. Le nom : le noyau du groupe nominal

Le nom désigne généralement une personne, un animal, une chose, un lieu, une idée ou un sentiment.

Exemples :

fille → personne
chat → animal
table → chose
Abidjan → lieu
courage → idée / qualité
Pour trouver le noyau du groupe nominal, demande-toi :

« De qui ou de quoi parle-t-on ? »

🎨 5. L'adjectif qualificatif

L'adjectif qualificatif donne une information ou une précision sur un nom.
Exemple :

Une grande maison.
Un garçon courageux.
Des fleurs magnifiques.

L'accord de l'adjectif

L'adjectif qualificatif s'accorde généralement en genre et en nombre avec le nom qu'il qualifie.

un garçon courageux
une fille courageuse
des garçons courageux
des filles courageuses
À retenir : Pour accorder correctement un adjectif, cherche le nom auquel il se rapporte.

➕ 6. Les expansions du nom

Une expansion du nom est un élément qui apporte des informations supplémentaires sur un nom.

L'adjectif qualificatif

une belle maison

Le complément du nom

le livre de français

La proposition subordonnée relative

le garçon qui joue dans la cour
Groupe nominal Expansion
une voiture rouge rouge → adjectif qualificatif
un sac de voyage de voyage → complément du nom
l'élève qui travaille qui travaille → proposition relative

🔬 7. Analyser un groupe nominal

Pour analyser un groupe nominal, on peut identifier la nature de chacun de ses éléments.

Exemple :

Le petit garçon courageux aide son ami.

Le → déterminant
petit → adjectif qualificatif
garçon → nom commun, noyau du GN
courageux → adjectif qualificatif
Méthode :
  1. Repère le groupe nominal.
  2. Cherche le nom noyau.
  3. Identifie le déterminant.
  4. Repère les adjectifs.
  5. Repère les éventuels compléments du nom ou relatives.

✏️ 8. Exercices

Exercice 1 — Trouver le groupe nominal

Recopie le groupe nominal dans chaque phrase.

  1. Le petit garçon joue dans la cour.
  2. Une grande maison se trouve près de l'école.
  3. Les élèves attentifs écoutent le professeur.
Correction :

1. Le petit garçon
2. Une grande maison
3. Les élèves attentifs

Exercice 2 — Trouver le nom noyau

Identifie le nom noyau de chaque groupe nominal.

  1. La jolie fleur
  2. Un grand arbre
  3. Les nouveaux élèves
  4. Le livre de français
Correction :

1. fleur
2. arbre
3. élèves
4. livre

Exercice 3 — Identifier les constituants

Analyse le groupe nominal suivant :

Les jeunes élèves courageux
Correction :

Les → déterminant
jeunes → adjectif qualificatif
élèves → nom noyau
courageux → adjectif qualificatif

Exercice 4 — Accorder les adjectifs

Mets l'adjectif entre parenthèses au bon genre et au bon nombre.

  1. Une fille (courageux).
  2. Des garçons (attentif).
  3. Une maison (grand).
  4. Des fleurs (magnifique).
Correction :

1. Une fille courageuse.
2. Des garçons attentifs.
3. Une maison grande.
4. Des fleurs magnifiques.

🧠 9. Quiz

Réponds aux cinq questions puis calcule ton score.

1. Quel est le noyau du groupe nominal « le grand arbre » ?
2. Quel mot est un déterminant ?
3. Quel mot est un adjectif qualificatif ?
4. Dans « le livre de français », quelle est l'expansion du nom ?
5. Dans « une grande maison », quel est le nom noyau ?

⭐ 10. L'essentiel à retenir

GN Groupe de mots organisé autour d'un nom.
Nom Il constitue généralement le noyau du GN.
Déterminant Il accompagne le nom.
Adjectif Il précise ou décrit le nom.
Expansion Elle apporte une précision supplémentaire au nom.
