Vocabulaire CM2

Enrichir son vocabulaire • Comprendre les mots • Bien les utiliser

📚 Introduction

Le vocabulaire est l'ensemble des mots que nous utilisons pour parler, lire, écrire et comprendre un texte.

À retenir : Plus on connaît de mots, plus on peut comprendre facilement ce que l'on lit et exprimer précisément ses idées.

En CM2, nous allons apprendre à reconnaître les relations entre les mots et à comprendre leurs différents sens.

1️⃣ Les synonymes

Définition : Deux mots sont synonymes lorsqu'ils ont un sens identique ou très proche.

Exemples :

Mot Synonyme
content heureux
maison habitation
commencer débuter
rapide vite
terminer achever
Attention : Les synonymes ne sont pas toujours interchangeables dans toutes les phrases. Il faut tenir compte du contexte.
Exemple :
« Cette voiture est rapide. »
On peut dire : « Cette voiture est vive. »

2️⃣ Les homonymes et homophones

Définition : Les homonymes sont des mots qui se ressemblent par leur prononciation ou leur forme mais qui n'ont pas le même sens.

Les homophones

Les homophones se prononcent de la même manière mais s'écrivent souvent différemment.

Mot Signification Exemple
mer étendue d'eau salée La mer est calme.
mère parent Ma mère cuisine.
maire responsable d'une commune Le maire parle aux habitants.

Autres exemples

verre / vert / vers / ver
pain / pin
sans / sang / cent / s'en
cour / cours / court

Astuce : Pour choisir le bon homophone, il faut comprendre le sens de la phrase.

3️⃣ Les contraires ou antonymes

Définition : Deux mots sont antonymes lorsqu'ils ont des sens opposés.
Mot Contraire
grand petit
chaud froid
entrer sortir
monter descendre
heureux malheureux
possible impossible

Les préfixes pour former des contraires

Certains contraires sont formés grâce à un préfixe.

possible → impossible
régulier → irrégulier
heureux → malheureux
honnête → malhonnête

4️⃣ Le sens propre et le sens figuré

Sens propre : c'est le sens réel et habituel d'un mot.
Sens figuré : c'est un sens imagé qui permet de créer une comparaison ou une image.
Expression Sens propre Sens figuré
avoir la tête dans les nuages avoir la tête près des nuages être rêveur
avoir un cœur de pierre avoir un cœur fait de pierre être insensible
donner sa langue au chat donner réellement sa langue abandonner une recherche ou une devinette
Exemple :
« Le lion marche dans la savane. » → sens propre.
« Cet homme est un lion. » → sens figuré : il est courageux.

5️⃣ Les noms composés

Définition : Un nom composé est formé de plusieurs mots qui fonctionnent ensemble pour désigner une seule réalité.

Exemples

Nom composé Éléments
porte-monnaie porte + monnaie
arc-en-ciel arc + en + ciel
chef-d'œuvre chef + d' + œuvre
gratte-ciel gratte + ciel
pomme de terre pomme + de + terre
Attention : Le pluriel des noms composés dépend de la nature des mots qui les composent. Il faut donc apprendre les règles et vérifier dans un dictionnaire en cas de doute.

6️⃣ Les familles de mots

Définition : Une famille de mots regroupe des mots construits à partir d'un même radical et qui ont un lien de sens.
Exemple : famille de « terre »

terre → terrestre → terrain → atterrir → déterrer

Le radical

Le radical est la partie commune que l'on retrouve généralement dans les mots d'une même famille.

chant → chanter → chanteur → chanson → chantonner

7️⃣ Préfixes et suffixes

Le préfixe

Le préfixe se place avant le radical et permet de former un nouveau mot.

faire → refaire
possible → impossible
charger → décharger

Le suffixe

Le suffixe se place après le radical.

jardin → jardinier
rapide → rapidement
heureux → heureté

8️⃣ Le champ lexical

Définition : Un champ lexical est l'ensemble des mots qui se rapportent à un même thème.
Champ lexical de l'école :
élève, professeur, classe, cahier, tableau, leçon, exercice, école, récréation, cartable.
Champ lexical de la mer :
bateau, plage, vague, poisson, sable, océan, pêcheur, coquillage.

9️⃣ Utiliser le dictionnaire

Le dictionnaire permet de connaître l'orthographe, la nature, le sens et parfois l'origine d'un mot.

Pour chercher un mot

  1. Regarder la première lettre.
  2. Comparer la deuxième lettre.
  3. Continuer jusqu'à trouver l'ordre alphabétique exact.
  4. Lire les différentes définitions.
  5. Choisir le sens correspondant à la phrase.
Exemple :
Le mot « feuille » peut désigner une partie d'une plante ou une feuille de papier. Le contexte permet de choisir le bon sens.

Exercice 1 — Synonymes

Trouve un synonyme pour chaque mot :

a) joli → ________
b) commencer → ________
c) terminer → ________
d) courageux → ________

a) beau
b) débuter
c) achever
d) brave
Exercice 2 — Contraires

Donne le contraire de :

a) grand → ________
b) ouvrir → ________
c) monter → ________
d) heureux → ________

a) petit
b) fermer
c) descendre
d) malheureux
Exercice 3 — Sens propre ou figuré ?

Indique si l'expression est employée au sens propre ou au sens figuré.

a) Il a cassé le verre.
b) Il a le cœur de pierre.
c) Le chat dort sur le canapé.
d) Cette nouvelle lui a brisé le cœur.

a) Sens propre
b) Sens figuré
c) Sens propre
d) Sens figuré
Exercice 4 — Familles de mots

Trouve deux mots de la même famille que :

a) terre → ________ / ________
b) chant → ________ / ________
c) fleur → ________ / ________

Exemples :
a) terrestre / terrain
b) chanter / chanteur
c) fleuriste / fleurir
Exercice 5 — Homophones

Complète avec le bon mot :

a) La ________ de mon village est très belle. (maire / mère)
b) Ma ________ prépare le repas. (maire / mère)
c) Le bateau est sur la ________. (mer / mère)
d) J'ai bu dans un ________. (verre / vert)

a) maire
b) mère
c) mer
d) verre
Exercice 6 — Champ lexical

Relève quatre mots appartenant au champ lexical de l'école :

rivière — cahier — tableau — forêt — professeur — élève — montagne

📌 À retenir

  • Synonymes : mots de sens identique ou proche.
  • Antonymes : mots de sens contraire.
  • Homophones : mots qui se prononcent de la même façon mais peuvent avoir une écriture et un sens différents.
  • Sens propre : sens réel du mot.
  • Sens figuré : sens imagé.
  • Nom composé : nom formé de plusieurs mots.
  • Famille de mots : mots construits autour d'un même radical.
  • Préfixe : élément placé avant le radical.
  • Suffixe : élément placé après le radical.
  • Champ lexical : mots associés à un même thème.
  • Dictionnaire : outil permettant de rechercher les informations sur un mot.
